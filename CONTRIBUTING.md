# Contributing

Follow README setup and run all listed checks before submitting a focused pull request. Explain behavior and validation. Contributions to project code are under GPL-3.0; preserve third-party notices.

Never commit credentials, environment files, databases, uploads, checkpoints or private datasets. Use synthetic fixtures and isolated test databases. Model/ensemble changes need documented evaluation methodology, dataset usage rights and limitations. Checkpoint filenames are not accuracy evidence.

Use issues for reproducible bugs and proposals. Report vulnerabilities privately as described in SECURITY.md.
